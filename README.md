## 💡 Purpose

**Physics PBA** is designed to bring practical physics learning into a modern, interactive, and easy-to-explore digital experience.

Instead of relying only on static content, the platform combines **experiments, apparatus, procedures, observations, calculations, graphs, and practice** in one organized interface.
